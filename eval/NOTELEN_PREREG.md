# 음 길이(노트 끝) 보정 — 사전 등록 (2026-11-21, 결과 보기 전에 고정)

배경: Round 4 재채점에서 dettato(General)는 노트 시작·음높이는 잘 맞지만 노트를 짧게 끊는다
(TRIOS 시작+끝 F1 0.371, 노트 길이 중간값 0.285 s 대 정답 0.485 s). `eval/ROUND4_REPORT.md` 끝 추가 절.

## 무엇을 바꾸나
dettato 전체 파이프라인(전사→증거 보정→악기 그룹→드럼)은 그대로 둔다. 끝난 결과에서 **드럼이 아닌 노트의 끝만** 뒤로 늘린다.
노트 시작·음높이·트랙·노트 수는 바꾸지 않는다(그래서 시작만 F1은 구조상 그대로여야 한다). 노트를 짧게 만들지는 않는다.

후보 (개발셋에서만 고른다):
- **R (모델 프레임 재해석)**: 같은 실행에서 전사기가 낸 frame/offset 확률 맵(두 voice 중 큰 값)을 써서, 노트 시작 이후
  frame 확률이 `fr_th` 아래로 `k` 프레임 연속 떨어지는 지점, 또는 offset 확률 봉우리가 `off_th` 이상인 지점(끄면 무시) 중 먼저 오는 곳을 새 끝으로 한다.
  같은 음높이의 다음 노트 시작을 넘지 않는다. 격자: `fr_th ∈ {0.4, 0.3, 0.2, 0.1}`, `off_th ∈ {0.3, 0.5, 0.7, 끔}`, `k ∈ {2, 4}`.
  (`fr_th 0.4, off_th 0.3, k 2`가 저자 기본값 — 대조군 재현 확인용)
- **E (단순 연장, 모델 무관 비교군)**: 같은 음높이 다음 시작까지 늘리되 최대 `x`초 늘림. `x ∈ {0.1, 0.2, 0.3, 0.5, 1.0}`.

## 데이터
- **개발셋**: Slakh train(`eval/heldout/data/slakh_train`) 매니페스트 앞 20곡, 30~90 s 창, 정답 `data/raw/slakh_train/<곡>/all_src.mid`의 드럼 제외 전체 노트.
  (grouper가 Slakh train으로 학습됐다. 노트 끝은 전사기가 정하므로 영향은 작다고 보지만 한계로 적는다.)
- **평가셋(한 번만 본다)**: Slakh test 20곡(Round 3와 같음), TRIOS 5곡(Round 4와 같은 정답·정렬 보정).
- 실제 녹음 개발셋이 없다. 신스(Slakh)에서 고른 설정이 실제 녹음(TRIOS)에 옮겨 가는지가 이번 질문의 핵심이다.

## 선택 규칙 (개발셋)
R·E 전체 후보 중 개발셋 곡별 시작+끝 F1(mir_eval, onset 50 ms, offset_ratio 0.2, offset_min 50 ms) 평균이 가장 높은 **하나**를 고른다.
평균 차이 0.005 이내면 더 단순한 쪽(E < R, R 안에서는 기본값에 가까운 쪽)을 고른다. 평가셋은 고를 때 보지 않는다.

## 판정 규칙 (평가셋, 고른 설정 하나만)
대조군은 **같은 실행의 보정 전 출력**(dettato 그대로)이다.
- **N1 (채택 권고)**: Slakh test(곡 단위 paired bootstrap 10,000회, seed 0)와 TRIOS(5초 구간 블록 bootstrap 10,000회, seed 0, micro F1)
  **둘 다** 시작+끝 F1 차이의 95% CI 하한 > 0, 그리고 두 세트 모두 시작만 F1 변화 |Δ| < 0.005.
- N1 통과 시: General dettato 경로에 이 보정을 기본으로 넣을 것을 권고(실제 반영은 사용자 결정, 공용 백엔드 재시작 필요).
- 한 세트만 통과하거나 둘 다 불통과: 기본 경로에 넣지 않는다. 결과만 기록.
- 결과를 본 뒤 규칙·후보·데이터를 바꾸지 않는다.
